# c1b3rseg.blog
Contenidos de c1b3rseg blog

## Publicación de notas

Las notas se redactan en Markdown en `publicaciones/` (una carpeta por nota,
nombrada `AAAA-MM-DD-titulo`) y se publican en Blogger con el
script `tools/publish.py` (Blogger API v3). Los adjuntos van en `assets/`.

Guía de configuración y uso: [tools/README.md](tools/README.md)
